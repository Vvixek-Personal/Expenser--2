Place SF Pro Rounded font files here for the "Rounded / Casual" typography setting:
- sf_pro_rounded_regular.ttf (or SF-Pro-Rounded-Regular.otf)
- sf_pro_rounded_bold.ttf (or SF-Pro-Rounded-Bold.otf)

When no font files are present, the app automatically and gracefully falls back to the system Sans Serif font without crashes or visual regressions.
